**Local Echo** - социальная сеть и краудсорсинговый инструмент для улучшения городской среды. Приложение позволяет жителям отмечать на интерактивной карте проблемы инфраструктуры (ЖКХ), локальные мероприятия и объявления, голосовать за них и формировать рейтинг самых активных граждан своего района.

## Ключевой функционал

### Для пользователей:
- [x] **Интерактивная карта:** Просмотр и фильтрация меток в зоне видимости экрана.
- [x] **Гео-тегинг:** Создание меток (Проблема, Мероприятие, Объявление) с загрузкой фото-подтверждений.
- [x] **Социальное подтверждение:** Голосование (Upvote/Downvote) за актуальность меток.
- [x] **Геймификация:** Начисление очков кармы авторам полезных меток.
- [x] **Лидерборд:** Рейтинг самых активных жителей по районам и всему городу.
- [ ] **Система комментариев:** Ветки обсуждений под каждой меткой *(В разработке)*.
- [ ] **Жалобы и репорты:** Система модерации контента *(Планируется)*.

### Архитектурные и технические фичи:
- [x] **Пространственные запросы (GIS):** Использование `PostGIS` и `NetTopologySuite` для сверхбыстрого поиска маркеров по квадрату координат (Bounding Box) с использованием GiST-индексов.
- [x] **Надежность данных:** Паттерн `Unit Of Work` и строгие ACID-транзакции для синхронного пересчета рейтинга маркера и кармы пользователя.
- [x] **Безопасность файлов:** Строгая валидация загружаемых изображений по "Магическим байтам" (File Signatures) и "компенсирующие транзакции" на фронтенде для удаления "файлов-сирот" при сбоях.
- [x] **Глобальная обработка ошибок:** Изолированная бизнес-логика без `try-catch` с использованием кастомного Middleware, возвращающего ошибки в стандарте **RFC 7807 (ProblemDetails)**.

### Backend
* **Фреймворк:** ASP.NET Core Web API
* **БД:** PostgreSQL + PostGIS (пространственные данные)
* **ORM:** Entity Framework Core (Code-First) + NetTopologySuite
* **Аутентификация:** JWT (Access + Refresh токены), ASP.NET Core Identity
* **Архитектура:** Clean Architecture, Repository Pattern, Unit of Work, DI.

### Frontend
* **Библиотека:** React 18 + TypeScript + Vite
* **State Management:** 
  * *Server State:* TanStack Query (React Query) v5
  * *Client State:* Zustand
* **Формы и Валидация:** React Hook Form + Zod
* **Карты:** Leaflet (`react-leaflet`, `react-leaflet-cluster`)
* **Архитектура:** FSD.
* **Стилизация:** CSS Modules
