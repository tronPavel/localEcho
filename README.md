# LocalEcho

## Описание
Приложение представляет собой гео-привязанную платформу, где пользователи могут отмечать на карте метки с различными проблемами или событиями. Например, можно указать место поломки, аварии или интересного мероприятия. Каждая метка содержит базовую информацию: заголовок, описание и статус (активна, в процессе, решена).

## Технологии
- **Бэкенд**: ASP.NET Core с использованием Clean Architecture, подключение к PostgreSQL с поддержкой PostGIS для работы с геоданными.
- **Фронтенд**: React с использованием Leaflet для отображения карты.
